# 🔥 LeechX — ربات لیچر تلگرام

ربات تلگرامی برای **دانلود از هر سایتی** و **آپلود مستقیم در تلگرام**، به‌همراه
**تبدیل فایل به لینک مستقیم** با انقضای خودکار.

ساخته‌شده برای کار با کاربر زیاد: صف کار، محدودیت همزمانی، پاک‌سازی خودکار دیسک،
و معماری ماژولار برای اضافه‌کردن قابلیت‌های بعدی.

---

## ✨ قابلیت‌ها

### ۱) لینک → انتخاب کیفیت → آپلود
- کاربر یک لینک می‌فرستد (یوتیوب، اینستاگرام، تیک‌تاک، توییتر/X، ساندکلاد، توییچ، ردیت و **۱۷۰۰+ سایت دیگر**).
- ربات عنوان، مدت و کاور را نشان می‌دهد و کیفیت‌های موجود را به‌صورت **دکمه** می‌آورد:
  - ویدیو: `144p` تا `2160p` (بهترین فرمت هر ارتفاع)
  - صدا: `MP3 192k` و `M4A`
- بعد از انتخاب کیفیت، **نحوهٔ تحویل** را انتخاب می‌کند: 🎬 ویدیو / 📄 فایل (Document) / 🔗 لینک مستقیم / ✏️ تغییر نام.
- فقط بعد از انتخاب نحوهٔ تحویل، کار دانلود و آپلود در صف قرار می‌گیرد.
- کپشن رسانه شامل **عنوان + لینک منبع + هشتگ‌های خودکار** است (`#YouTube`، `#Instagram`، `#Shorts`، `#Reels`، `#Video`، `#Audio`، `#File` و…) و روی همان پیام رسانه می‌نشیند.
- **هیچ فایلی روی سرور نمی‌ماند** — پوشهٔ کار بلافاصله بعد از آپلود (یا خطا) پاک می‌شود.
- لینک مستقیم (مثل `.../movie.mp4`) **بدون** پرسیدن کیفیت مستقیم به صفحهٔ تحویل می‌رود.

### ۲) فایل → لینک مستقیم
- کاربر فایل/ویدیو/موزیک می‌فرستد، لینک مستقیم می‌گیرد.
- پیش‌فرض **۶ ساعت** اعتبار (از پنل ادمین قابل تغییر).
- دانلود بازه‌ای (`Range`) پشتیبانی می‌شود → پخش و seek در مرورگر/VLC.
- بعد از انقضا، فایل و رکورد خودکار حذف می‌شوند.

### ۳) پنل ادمین (فقط ادمین‌ها می‌بینند)
- 📈 آمار زنده: کاربران کل/فعال/مسدود، تعداد نفراتی که همین حالا آپلود می‌کنند، لینک‌های مستقیم فعال، گزارش‌های باز، کارهای ۲۴ ساعت، دیسک و آپتایم
- 🧾 کارهای اخیر با وضعیت و مشخصات کاربر
- 👥 **گروه ادمین با تاپیک**: یک گروه دارای Topics بساز، ربات را ادمین کن و داخل گروه `/setup` بزن. چهار تاپیک خودکار ساخته می‌شود: دانلود، آپلود، گزارش‌ها، لاگ‌ها
- 🔔 اعلان دانلود/آپلود همراه نام، یوزرنیم و آیدی عددی کاربر
- 🚫 بن کردن با **فوروارد پیام**، `@username` یا آیدی عددی + رفع مسدودی
- 🚨 گزارش‌ها: سایت‌های خراب/پشتیبانی‌نشده و پیام‌های کاربران؛ با یک دکمه بسته می‌شوند
- 🐞 لاگ‌ها: خطاهای ربات و کارها با منبع، زمان و کاربر + پاک‌سازی
- 🛠 **متغیرهای اجرا**: API ID/Hash، آدرس Local Bot API، پروکسی و آدرس عمومی را از داخل ربات وارد کن (بدون دست‌زدن به env سرور)
- ✉️ دکمهٔ «ارتباط با ادمین» برای همهٔ کاربران
- 👥 افزودن/حذف ادمین
- ⚙️ تنظیمات زنده: TTL لینک، سقف آپلود، سقف فایل لینک، محدودیت نرخ، سهمیهٔ روزانه، حالت تعمیر، سایت‌های بزرگسال
- 📢 پیام همگانی
- 🔎 جست‌وجوی کاربر
- 🍪 مدیریت کوکی‌ها: آپلود/پیست `cookies.txt`، بررسی سلامت و حذف فایل
- 🧹 پاک‌سازی دستی فایل‌های منقضی

### ۴) دیتابیس سایت‌ها
- `/sites` → تعداد و لیست سایت‌های محبوب
- `/sites اینستاگرام` → جست‌وجو در ۱۷۵۰+ اکسترکتور
- با هر `pip install -U yt-dlp` لیست سایت‌ها خودکار به‌روز می‌شود.

### ۵) نسخه، دیپلوی و عیب‌یابی (نسخهٔ ۵)
- 🌍 **سه زبان**: فارسی 🇮🇷، انگلیسی 🇬🇧 و روسی 🇷🇺؛ دکمهٔ تغییر زبان در منو و `/lang`. زبان کلاینت تلگرام در اولین پیام خودکار تشخیص داده می‌شود.
- 🏷 **نسخهٔ دقیق**: منبع واحد نسخه `app/version.py` است و در `/start`، `/me`، آمار ادمین و تنظیمات نمایش داده می‌شود. `tests/test_version.py` هم‌خوانی آن با `pyproject.toml` و `CHANGELOG.md` را بررسی می‌کند.
- 📦 **دیپلوی از داخل ربات**: پنل ادمین → 🚀 دیپلوی → دانلود ZIP سورس، اعتبارسنجی ZIP جدید، بکاپ خودکار در `data/updates/`، اعمال و ری‌استارت. فایل‌های `.env` و `data/` هرگز داخل ZIP نمی‌روند و از ZIP ورودی هم نوشته نمی‌شوند.
- 🔐 **عضویت اجباری**: در پنل ادمین → 👥 گروه‌ها → عضویت اجباری. بررسی عضویت کش می‌شود و اگر تلگرام خطا بدهد کاربر قفل نمی‌شود.
- 👁 **پیش‌نمایش کاربر**: ادمین می‌تواند ربات را دقیقاً مثل یک کاربر عادی ببیند و با یک دکمه برگردد.
- 🩺 **توکن عیب‌یابی زمان‌دار**: حداکثر ۲۴ ساعت، سه سطح `read/write/restart`، ذخیرهٔ هش‌شده و قابل ابطال. راهنمای کامل: [`docs/DEBUG_API_FA.md`](docs/DEBUG_API_FA.md).
- ⌨️ **بستن کیبورد** با دکمه (مثل خود تلگرام)، نه با دستور.
- 🔄 **به‌روزرسانی yt-dlp** (stable/nightly) از پنل + بازسازی خودکار فهرست سایت‌ها.

## 🚀 نصب

### الف) Docker (پیشنهادی)

```bash
git clone <repo-url> leechx
cd leechx

cp .env.example .env
# فقط BOT_TOKEN را پر کن؛ OWNER_IDS اختیاری است
# اگر BOT_TOKEN خالی باشد، اجرای `python main.py` خودش توکن را می‌پرسد و ذخیره می‌کند

docker compose up -d --build
docker compose logs -f
```

برای دیدن لینک‌های مستقیم از بیرون، `PUBLIC_BASE_URL` را روی دامنه/IP سرور بگذار.

### ب) اجرای مستقیم

```bash
python -m venv .venv
source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

# ffmpeg لازم است (برای ادغام ویدیو+صدا و تبدیل MP3)
# اوبونتو: sudo apt install ffmpeg
# ویندوز: winget install Gyan.FFmpeg

cp .env.example .env
python main.py --check   # بررسی تنظیمات + دیتابیس
python main.py
```

> **راه‌اندازی با فقط توکن:** اگر `BOT_TOKEN` را در `.env` نگذاری، همین اجرا از تو
> می‌پرسد و در `.env` ذخیره می‌کند. اولین کاربری که `/start` بزند به‌عنوان **مالک**
> شناخته می‌شود و دکمهٔ «پنل ادمین» را می‌بیند. برای گروه ادمین، ربات را به یک گروه
> دارای Topics اضافه کن، ادمینش کن و داخل گروه `/setup` بفرست.

### ج) آپلود فایل‌های بزرگ‌تر از ۵۰ مگابایت

Bot API معمولی سقف ۵۰MB برای آپلود و ۲۰MB برای دانلود دارد. برای ۲GB:

```bash
docker compose --profile localapi up -d
```

و در `.env`:

```env
TELEGRAM_API_URL=http://telegram-bot-api:8081/bot
TELEGRAM_API_FILE_URL=http://telegram-bot-api:8081/file/bot
TELEGRAM_API_ID=123456
TELEGRAM_API_HASH=abcdef...
```

`API_ID` و `API_HASH` را از [my.telegram.org](https://my.telegram.org) بگیر.

## ⚙️ تنظیمات

همه در `.env` — نمونهٔ کامل: [`.env.example`](.env.example)

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات از @BotFather |
| `OWNER_IDS` | خالی | اختیاری؛ اگر خالی باشد اولین `/start` مالک را تعیین می‌کند |
| `ADMIN_IDS` | خالی | ادمین‌های اضافی |
| `PUBLIC_BASE_URL` | `http://127.0.0.1:8080` | آدرس عمومی برای لینک‌های مستقیم |
| `PORT` | `8080` | پورت وب‌سرور داخلی |
| `LINK_TTL_HOURS` | `6` | اعتبار پیش‌فرض لینک |
| `MAX_UPLOAD_MB` | `2000` | سقف آپلود به تلگرام |
| `MAX_LINK_FILE_MB` | `2000` | سقف فایل برای لینک مستقیم |
| `WORKERS` | `2` | تعداد کارگرهای دانلود/آپلود |
| `PER_USER_CONCURRENCY` | `1` | کار همزمان هر کاربر |
| `RATE_LIMIT_SECONDS` | `3` | فاصلهٔ بین درخواست‌های هر کاربر |
| `DAILY_QUOTA` | `0` | سهمیهٔ روزانه (۰ = بی‌نهایت) |
| `PROXY` | خالی | پروکسی دانلود |
| `COOKIES_DIR` | `./data/cookies` | کوکی‌ها برای سایت‌های محدودشده |
| `DEFAULT_LANG` | `fa` | زبان پیش‌فرض (`fa`/`en`) |
| `NSFW_ENABLED` | `true` | فعال‌بودن سایت‌های بزرگسال |

### کوکی‌ها (یوتیوب/اینستاگرام)

اگر یوتیوب «Sign in to confirm you're not a bot» داد یا اینستاگرام محتوا را نشان نداد:

1. وارد **👑 پنل ادمین → 🍪 کوکی‌ها → ➕ افزودن / آپلود** شو.
2. فایل `cookies.txt` را (به‌صورت Document) بفرست یا متن Netscape را پیست کن.
3. نام فایل خودکار از دامنه ساخته می‌شود: `data/cookies/youtube.txt`،
   `data/cookies/instagram.txt` و…
4. با **🧪 بررسی** سلامت فایل را چک کن.

فرمت Netscape (خروجی افزونهٔ «Get cookies.txt LOCALLY» یا «EditThisCookie»)؛
خروجی JSON بعضی افزونه‌ها هم خودکار تبدیل می‌شود. سقف حجم ۲ مگابایت.

راهنمای کامل با مراحل، امنیت و خطاهای رایج:
[`docs/COOKIES.md`](docs/COOKIES.md)

## 📈 مقیاس‌پذیری

- **SQLite** پیش‌فرض است و برای شروع کافی. برای ترافیک بالا:

```env
DATABASE_URL=postgresql+asyncpg://user:pass@host:5432/leechx
```

(نیاز به `pip install asyncpg`)

- `WORKERS` را با تعداد هسته/پهنای‌باند تنظیم کن.
- برای چند سرور، `RateLimiter` و `DraftStore` را با Redis عوض کن (رابط یکسان است).
- دیتابیس کارها (`jobs`) تاریخچهٔ کامل را نگه می‌دارد؛ برای آمار سنگین از آن استفاده کن.

## 🔐 امنیت

- لینک‌های مستقیم **HMAC امضاشده** و منقضی‌شدنی‌اند؛ قابل حدس نیستند.
- مسیر فایل‌ها همیشه داخل `data/files/links` اعتبارسنجی می‌شود (ضد path traversal).
- توکن ربات و کلیدها فقط در env هستند و در دیتابیس ذخیره نمی‌شوند.
- ربات باید **خصوصی** بماند؛ `OWNER_IDS` را دقیق تنظیم کن.
- پورت `8080` را می‌توانی پشت Nginx/Caddy با HTTPS بگذاری.
